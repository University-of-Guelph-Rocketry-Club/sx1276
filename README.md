# SX1276 Radio Chip Driver
Radio chip driver for the UoG Rocketry club.

Note that no uplink is implemented/available so transmission is done on the satellite/rocket and reception on the ground station *only*.

# Project Structure
- The `third-party` folder contains vendored/third-party code. Currently it contains the `MANTLE` protocol implementation.
- The `Core`, `Drivers`, `STM32F411xx_FLASH.ld` and `startup_stm32f411xe.s` files are generated by STM32CubeMX and are needed for building the driver.
    - Building the driver is done using the `Makefile` in this project.

# Building and Flashing
```sh
make
st-flash write driver.bin 0x8000000
```
